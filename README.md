# Oregon Bound

Unofficial Oregon Trail-style wagon game. Not affiliated with The Oregon Trail brand.

**Play:** https://mousoforge.github.io/oregon-bound/

## iPhone install

1. Open the play URL in **Safari**.
2. Share → **Add to Home Screen**.
3. Launch from the icon.

If that URL 404s, enable Pages once:
Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/` (root) → Save**.
Wait one minute, then reload the play URL.
